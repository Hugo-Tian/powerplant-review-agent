# Vue 工作台

新增前端位于 `frontend-vue/`，旧 React 前端保留在 `frontend/`。主入口 `src/App.vue`，请求封装 `src/api.js`，视觉样式 `src/style.css`。

界面采用蓝灰色工作台，设备等级和审核状态采用不同文字与色彩；桌面为工单队列与详情双栏，窄屏改为上下布局，表格允许横向滚动。使用系统中文字体，不需要外部字体或 CDN。

功能包括：

- 选择三个明确标为模拟的岗位画像。
- 导入全部 320 条模拟工单并实时调用推理，展示导入进度，跳过已存在工单；失败保留已完成部分。
- 全量读取当前岗位工单后搜索、筛选、按当前有效匹配分或写入顺序排序，每页 10 条。
- 查看模型原评分、理由、标签、历史和人工反馈；不将分数转写为置信概率。
- 人工确认原模型结果，或修改评分和推送类型，填写审核人及理由，写入 SQLite。
- 新建原文工单并立即预测，展示加载、空列表、无搜索结果、连接错误和保存状态。

开发：后端 `demo_api:app` 运行于 8000，`npm run dev` 运行 Vite 5173。构建：`npm run build`，后端重启后在根路径 `/` 提供构建页面。`/api` 为前端请求别名，原裸路径 API 继续保留；`/docs` 和 `/openapi.json` 在 Vite 开发模式下也代理到后端。

浏览器流程测试 `npm run test:e2e` 自动启动 8766 端口的临时服务，使用独立数据库，不修改 `data/demo.sqlite3`。需要先构建并通过 `npx playwright install chromium` 安装测试浏览器。截图保存在 `docs/images/`。端口需空闲；前端每次变更后需要重新构建再运行测试。

无登录功能，岗位是本地演示选择器。用户画像来自模拟数据，反馈用于留痕与人工业务判断，不自动更新模型参数。
